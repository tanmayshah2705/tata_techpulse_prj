## Overview

AutoCodeGuard is a Streamlit web application that helps developers identify potential programming defects in source code using:

1. **Deterministic static analysis** — rule-based Python AST + regex checks  
2. **Gemini AI review** — LLM-powered advisory findings via Google's Gemini API  
3. **TF-IDF guideline retrieval** — relevant coding guidelines from a local JSON knowledge base

> ⚠️ This is a **student prototype** for educational purposes. Findings are heuristic potential issues, not confirmed vulnerabilities.

## Configuration

Create a `.env` file in the **project root** (the AutoCodeGuard folder, NOT inside Code/):

```
GEMINI_API_KEY=your_api_key_here
```

> 🔒 **Never commit `.env` to version control.** It is already in `.gitignore`.

The Gemini model is configured in `Model_Prompts_Config/model_config.json`.  
Default: `gemini-flash-lite-latest` (with automatic Lite fallbacks)

## Running the Application

```bash
# From the Code/ directory
streamlit run app.py
```

The app opens at `http://localhost:8501` in your browser.

## Usage

1. **Paste** code in the text area, or **upload** a `.py`, `.c`, `.java`, etc. file.
2. Select the **source language** in the left sidebar.
3. Toggle **Gemini AI Review** on/off (off = no API call, no internet required).
4. Click **🔍 Run Review**.
5. Review the findings dashboard.
6. Download the **JSON report** or **CSV** exports.

## Static Analysis Rules

| Rule ID     | Type    | What it detects                        | Severity |
|-------------|---------|----------------------------------------|----------|
| ACG-PY-001  | AST     | `eval()` / `exec()` usage              | HIGH     |
| ACG-PY-002  | AST     | `subprocess` with `shell=True`         | HIGH     |
| ACG-PY-003  | AST     | Bare `except:` clause                  | MEDIUM   |
| ACG-PY-004  | AST     | `assert` for input validation          | LOW      |
| ACG-PY-005  | AST     | Mutable default arguments              | LOW      |
| ACG-PY-006  | AST     | `os.system()` calls                    | HIGH     |
| ACG-RE-001  | Regex   | Hardcoded credentials/secrets          | HIGH     |
| ACG-RE-002  | Regex   | Weak hash (MD5, SHA-1)                 | HIGH     |
| ACG-RE-003  | Regex   | SQL query built with string formatting | HIGH     |
| ACG-RE-004  | Regex   | TODO / FIXME markers                   | MEDIUM   |
| ACG-RE-005  | Regex   | `DEBUG = True` in source               | HIGH     |
| ACG-RE-006  | Regex   | `print()` diagnostic statements        | MEDIUM   |

## Limitations

- Static analysis covers a small rule set; not a certified SAST tool.
- Gemini requires a valid API key and an internet connection.
- Gemini-generated line numbers are approximate (heuristic).
- LLM findings are advisory only — always review manually.
- Supports Python best with AST analysis; other languages use regex rules only.
- Not suitable for production automotive certification.

---

## Privacy & Security

- The API key is loaded from `.env` and never printed, logged, or displayed.
- Source code is sent to Google's Gemini API only when the user explicitly requests a review and confirms the privacy notice.
- No user code or findings are stored persistently by this application.
